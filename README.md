# ASCII Logo from PNG — чистые HTML, CSS и JavaScript

Проект преобразует прозрачный PNG-логотип в ASCII-отрисовку средствами Canvas 2D.
Сторонние библиотеки, Node.js и сборка не нужны.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Если браузер ограничивает загрузку локальных изображений при открытии через `file://`,
запустите папку через VS Code Live Server или любой простой локальный HTTP-сервер.

## Файлы

- `assets/logo.png` — исходный логотип, который вы прислали.
- `index.html` — разметка страницы.
- `css/style.css` — оформление страницы.
- `js/config.js` — настройки эффекта.
- `js/main.js` — чтение пикселей PNG и отрисовка символов в Canvas.

## Настройка

В `js/config.js`:

- `colorMode: "ice"` — голубовато-белая палитра в духе референса.
- `colorMode: "original"` — приближённо сохраняет исходные цвета.
- `sampleStep` — плотность символов. Уменьшайте для большей детализации.
- `depthLayers` — число слоёв имитации объёма.
- `depthOffset` — расстояние между слоями.
- `glyphs` — набор ASCII-символов.
- `glow` — сила свечения.
- `stars` — количество фоновых звёзд.

## Как это работает

JavaScript загружает PNG, считывает цвет и прозрачность каждого небольшого участка,
отбрасывает прозрачный фон и размещает ASCII-символ в координатах исходного пикселя.
Несколько сдвинутых копий формируют иллюзию глубины. Это 2D-отрисовка с псевдо-3D,
а не настоящая 3D-модель.
